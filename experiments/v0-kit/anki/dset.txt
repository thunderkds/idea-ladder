Why is writing by path harder than reading by path?	Reading can stop and return nothing at a missing level. Writing must invent the missing levels and choose a type for each: plain object or array.	idea-ladder dset L0
What is prototype pollution?	An attacker-controlled key such as the prototype link name makes a write land on the shared base object. Every object then inherits the attacker's value.	idea-ladder dset L0

In JavaScript, why is the typeof check on null a classic trap?	The typeof operator reports object for null. Code that tests for an object by typeof alone treats null as something it can read properties from, and then throws.	idea-ladder dset L0
