High P1 src/client/offline-store.ts syncQueue (401 branch), signedOut() 
A 401 clears the whole offline store, queue included. A session that expires while ratings made offline are still unsynced (or a 401 from any API call such as /api/review/queue on the next online visit) silently destroys that learner's unsynced reviews; the guide treats unsynced ratings as the one thing that must survive (edge case: queued ratings are lost only if never synced). The same applies to Review.tsx and LadderView.tsx, which call signedOut() on a 401. Only an explicit sign-out should delete the queue. Confidence 85. Action: on a 401 clear the cached packs and the service-worker caches (no card text stays readable) but keep the queue and meta.learner, so the same learner's ratings sync after the next sign-in; add a test (queue survives a 401, then syncs after sign-in; another learner never sees or sends it).
